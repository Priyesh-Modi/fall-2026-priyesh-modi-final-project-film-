**The pitch in one sentence:** an agent that answers coding questions from a library's official docs, pinned to the version you're using, and checks its own answers. It quotes the section it used, runs any code against that version, and refuses when the docs don't cover the question. The headline result will be a dated comparison against a plain model.

**What exists today:** only the Pydantic v2.14.1 docs snapshot, cloned 2026-10-24 (see `SNAPSHOT.md`), and this pitch. Beats B02 and B13 show that real data on screen. Every drawn beat about the future is tagged "plan · not built" on screen and uses "will" in the narration. B03 is tagged "my comparison" and B16 "about me".

## Rebuild

See `BUILD-PROMPT.md`. In short:

```bash
source ~/INFO7375/.venv/bin/activate && cd pinned-docs-pitch && export ART_HOME=~/INFO7375/brutalist.art
python3 make_sheet.py && python3 $ART_HOME/runtime/scripts/generate_audio_kokoro.py . && python3 finish_audio.py
python3 $ART_HOME/runtime/scripts/align.py . && python3 make_sheet.py && python3 build_reel.py
$ART_HOME/art run . --height 2160 && $ART_HOME/art final . --height 2160 --out exports/landscape
```

Everything runs locally for $0 (Kokoro, Manim, Remotion). No API keys, no uploads.
